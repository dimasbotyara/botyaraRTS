# botyaraRTS — большой апгрейд

(план утверждён тобой в чате; единственное изменение — в конце делаю несколько логических коммитов с внятными сообщениями без "v2"/"rewrite" и пушу на remote)

## Context
Проект — процедурный pygame-RTS (~12.8k строк). Сейчас: ИИ — 38 строк (только рабочие), мультиплеер — не подключённая заглушка, ни одной картинки/иконки, тестов нет, экран загрузки замирает на «20%» (весь мир генерируется одним синхронным вызовом `GameState()` в `core/game.py:399`). Кластеры ресурсов раскиданы равномерно-случайно. Цель — всё из запроса: графика, продвинутый ИИ со сложностями/стратегиями/сдачей, реальный LAN-мультиплеер с лобби, настройки создания игры, аккуратные ресурсы, фикс загрузки, баннеры/иконка, README и тесты.

## Фаза 0 — фикс экрана загрузки + фундамент
1. **Инкрементальная загрузка**: `TileMap.generate_iter()` (полосы по 16 рядов), чанкинг пре-рендера миникарты и деталей террейна; в `Game.run()` — `STATE_LOADING`: каждый кадр берёт следующий чанк, рисует анимированный экран (звёздное поле двигается), обрабатывает события.
2. **Произвольный размер карты** (S=176/M=256/L=320): `GameState` принимает tilemap; `FogOfWar`/`Minimap`/`Camera` — размеры от карты, не константы.
3. **2-4 спавна**: 2 = диагональ, 3 = треугольник, 4 = углы; BFS-связность всех пар.
4. **Аккуратные ресурсы**: компактные круглые патчи, зеркальная симметрия, мин-дистанции, гейзеры парами, гарантированная база у спавна; RNG в изолированных `random.Random(seed)`.

## Фаза 1 — экран создания игры
`STATE_CREATE_MATCH` + `ui/widgets.py`: оппоненты 1-3, сложность ИИ (Новобранец/Солдат/Ветеран/Кошмар), стратегия ИИ (случайно/конкретная), размер карты, стартовые ресурсы, плотность ресурсов, seed. Сохранение последних значений в `game_settings`.

## Фаза 2 — продвинутый ИИ (`ai/`)
Детерминированный: таймеры на dt тика, случайность только через `gs.rng`.
- `ai/config.py` — 4 сложности (интервал мышления, реакция, ошибки, handicap дохода, дисциплина).
- `ai/strategies.py` — 9 стратегий с билд-ордерами: balanced, rush, defense/turtle, air_only, eco, swarm, tech (Punisher), siege, harass + random.
- `ai/macro.py` — экономика/билд-ордер/supply; `ai/commander.py` — армия: состав, отряды, триггеры атак, отступления, оборона; `ai/brain.py` — оркестратор на каждого ИИ.
- `systems/commands.py`: общий `place_building_at()` для UI и ИИ.

## Фаза 3 — сдача бота
`ai/surrender.py` — оценка безнадёжности (армии, здания, ресурсы, потери). Одно предложение за матч: панель сверху «Принять победу» / «Заставить играть дальше»; отказ → desperate-режим бота.

## Фаза 4 — текстуры
`rendering/sprite_cache.py` (пре-рендер по (класс, команда, угол, зум)); апгрейд всех рендереров: контуры, градиенты, командные панели, анимации (гусеницы/роторы/покачивание), поворот башен к цели, повреждения (дым), стройка (леса); терраин: свет по высоте, пена воды, грани кристаллов, пар гейзеров. `main.py`: `set_icon()`.

## Фаза 5 — LAN-мультиплеер
Фиксированный тик `SIM_DT=1/30` (сим отделена от клиентской части); `random.*` в симуляции → `gs.rng`; протокол v2 (join/lobby/settings/seq-stamped команды/sync-hash); переработка server.py/client.py; `network/commands.py` — сериализация команд (move/attack/build/produce/...); экраны MP-меню и лобби (готовность, чат, настройки хоста, ИИ-слоты до 4 игроков); рассинхрон-детектор; пауза через голоса.

## Фаза 6 — баннеры и иконка
`assets/branding/`: banner_en/ru.svg (1280×400 тёмный sci-fi) → PNG (rsvg-convert); icon.svg → 512/64 PNG; visual-judge проверка.
